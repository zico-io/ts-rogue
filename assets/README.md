# Assets

- `urizen_onebit_tileset__v2d0.png` - [Urizen 1-bit tileset v2.0](https://vurmux.itch.io/urizen-onebit-tileset) by vurmux, CC-BY-4.0. 12 px tiles on a 13 px pitch (1 px outer margin and gutters).

Tiles render via the kitty graphics protocol (Ghostty/kitty). Inside tmux you need `set -g allow-passthrough on` (tmux >= 3.3, off by default).
